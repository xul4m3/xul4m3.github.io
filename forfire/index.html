forFIRE

個人自用的財務記錄工具，只供開發者本人使用。

A personal finance record-keeping tool used only by its developer.

隱私權政策 · Privacy Policy

  • 只存取授權者本人的 Gmail，權限為唯讀（gmail.readonly），只查詢特定寄件者。
  • 資料只存在使用者自己的電腦，不傳送、分享或出售給任何第三方，不用於廣告。
  • 遵守 Google API Services User Data Policy（含 Limited Use 規定）。
  • 可隨時於 Google 帳戶「第三方連結」撤銷授權。
  • Accesses only the authorizing user's own Gmail, read-only (gmail.readonly), and only messages from specific senders.
  • Data stays on the user's own computer. It is never transferred, shared or sold to third parties, and never used for advertising.
  • Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time from the Google Account third-party connections page.
